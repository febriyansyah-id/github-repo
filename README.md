This hub coordinates multiple specialized repositories spanning four core technical domains:

1. **Cybersecurity & Offensive Security:** Red Teaming, Digital Forensics & Incident Response (DFIR), Active Directory exploitation, and Hack The Box achievements.
2. **Data Science, AI & Machine Learning:** End-to-end ML workflows, Deep Learning architectures (CNNs, Transformers, Mamba), Big Data engineering, and LLM implementations.
3. **Enterprise Infrastructure & Presales:** Reusable infrastructure toolkits, Docker stacks, network discovery engines, and monitoring daemons.
4. **Academic Research & Publications:** Postgraduate research in *Magister Teknik Informatika* (MTI), comprehensive paper reviews, and lecture archives.
